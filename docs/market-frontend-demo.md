# 市场情报中心前端演示

入口：业务网站 `/centers/1/`。保留总览与其余八个业务中心。

## 界面与交互

- 四个模块：市场发现、竞争分析、细分市场、机会评估。每个模块有独立筛选字段和内存草稿；切换模块保留草稿，刷新页面后草稿重置。
- 表单：500 字研究需求、模块适用条件、数值区间校验、六个可选扩展条件、示例模板和重置。未填写条件始终显示“待确认”；“不限”需要主动选择。
- 研究记录、任务管理、任务历史及报告中心共用 `DemoRecord[]`；不复制成多套模拟任务列表。
- 状态：待开始、执行中、暂停中、已完成、已取消；所有状态、阶段进度和按钮均标记为演示。状态只通过用户操作切换，不运行定时器伪装自动研究。
- 报告：完成状态提供需求、条件摘要和后续待验证事项的结构示例，可导出 Markdown；不产生亚马逊市场数据或推荐结论。

## 数据边界

代码位于 `apps/web/lib/market-demo.ts` 与 `apps/web/components/market-intelligence.tsx`，不调用 `/api/`、模型或市场数据接口。浏览器 localStorage 使用独立键 `swanyo.market.frontend-demo.v1`，与真实后台数据体系隔离。记录以任务 ID 关联历史及报告，最多保存 100 项。损坏的本地数据会回退到明确标记的示例记录；存储不可用时提示刷新后可能丢失。

初始三个任务用于展示执行中、暂停中和完成样式，所有筛选值为空，不包含虚构的销量、利润、品牌份额或类目推荐。已保存任务可刷新保留；不跨浏览器或电脑同步。

## 验证

```sh
npm run typecheck -w @swanyo/web
npm run build -w @swanyo/web
node --experimental-strip-types --test tests/market-demo.test.ts
```

新增测试覆盖模块字段差异、待确认语义、区间校验、输入快照、状态转换历史、终止状态、报告边界和本地数据解析。可把 `apps/web/out` 作为纯静态站点预览，无需启动后端。
